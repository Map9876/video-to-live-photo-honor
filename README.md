# video-to-live-photo-honor

把**视频转成荣耀相册可识别的 LivePhoto（动态照片）**的纯静态网页工具。全程在浏览器本地处理，视频不会上传到任何服务器。

## 背景
荣耀手机相册对动态照片（LivePhoto）的识别规则与谷歌 / 苹果不同：在图片里嵌入的 XML 元数据比标准格式多了一小段，所以通用方案生成的动态图在荣耀相册里只会显示成静态图。本项目按荣耀的封装格式直接生成，确保相册能正常播放动态效果。

## 封装格式：与苹果 / 谷歌标准 LivePhoto 的关系

LivePhoto 的本质都是「**一张静态封面图 + 一段短视频**」，三者都用电 H.264/AVC 的 MP4 当动态部分，区别只在封面与视频**如何打包**：

- **苹果 Live Photo**：不是单个文件，而是相册里的**一对文件**——`IMG_xxxx.JPG`（静态封面）+ `IMG_xxxx.MOV`（约 3 秒 H.264/AAC 短片，拍摄瞬间前后各约 1.5 秒）。两者靠 JPEG 的 TIFF/maker-note 与 MOV 元数据里相同的 `ContentIdentifier` 关联，而非某个统一容器。
- **谷歌 Motion Photo / Micro Video**（Google Photos 与众多安卓厂商通用）：**单文件**——把短视频作为第二段流塞进 JPEG 容器。具体是在 JPEG 的 `FFD9`（EOI，图像结束标记）之后追加一段 MP4，并在 JPEG 头部写一段 **XMP 元数据** `Camera:MotionPhoto="1" / Camera:MicroVideoOffset="..."` 指出视频的偏移与长度，相册据此把尾部数据当视频播放。

**荣耀 / 华为「动态照片」** 采用了与谷歌一致的「**单文件 = 封面 JPEG + 视频**」思路，但**没有用 XMP 指针**，而是约定在文件**尾部追加一段固定 60 字节的 ASCII trailer** 来描述视频。本项目按此格式直接生成，因此荣耀相册能识别为实况；而通用方案（仅塞 MP4 或只写 XMP）在荣耀里只会显示成静态图。

### 本工具生成的文件布局（`*.livephoto.jpg`）

```
┌─────────────────────┐
│ 封面 JPEG（静态海报） │  ← 选段封面帧，最长边裁到 1920，质量 0.9
├─────────────────────┤
│ MP4 视频（动态部分）  │  ← H.264/AVC，WebCodecs 逐帧编码，PTS 严格均匀
├─────────────────────┤
│ 60 字节 trailer      │  ← 3 行 × 20 字节，右侧空格补齐
│  · v2_fNN            │    最佳时刻帧序号（f00..f99），仅 bestMoment 写入
│  · <startMs>:<durMs> │    动态段起点(ms):时长(ms)
│  · LIVE_<len+0x14>   │    "LIVE_" + (MP4字节数 + 0x14)，十进制
└─────────────────────┘
```

> trailer 三段格式严格对齐荣耀真机样本（已用实机自证）；`0x14`(=20) 即单行 20 字节的占位长度。它与谷歌 XMP 方案作用相同（告诉相册「视频在哪、多长、最佳帧在哪」），只是换成了更简单的定长尾部。

### 生成流水线

1. **选段**：从源视频里框出要保留的动态区间 `sel.start ~ sel.end`（胶片条拖拽 / 单帧步进）。
2. **封面 JPEG**：在 `coverT`（默认区间起点）抽帧，`drawImage` 缩放至最长边 1920，`toDataURL('image/jpeg', 0.9)`。
3. **动态视频**：WebCodecs `VideoEncoder`（H.264，baseline 3.1 优先、不支持则 high 3.0）**逐帧 `seek`→绘帧→编码**，`mp4-muxer` 封装；时间戳按源帧率严格均匀（`i/帧率`），保证播放丝滑（不再依赖会被浏览器节流的隐藏视频回调）。
4. **封装**：`Blob([封面JPEG, MP4, trailer])` → 以 `<原名>.livephoto.jpg` 下载。

## 基本用法
1. 点击任意位置，选择一段 MP4 / MOV 视频（竖屏、横屏均可）。
2. 底部胶片条会按 0.5s/帧 真实抽帧生成缩略图。
3. 拖动红色「保留段」的左右两个粉色轴，框出要保留的动态区间；也可直接拖动整段矩形平移。
4. 用 `后退一帧` / `前进一帧` 按钮让两个粉色轴**同步整体前进 / 后退一帧**（按视频真实帧率），画面实时预览选段当前帧。
5. 点「设封面」设定动态照片封面帧；点「导出」生成 LivePhoto 并下载。

## 时间轴特性
- **统一的同步层**：整条底部胶片条与进度条是同一个可拖动层。拖动任意位置即同时平移胶片条并移动播放头，抓取的帧贴着手指。
- **双指持续放缩**：以两指焦点帧为中心缩放，松手保持；缩放范围从「整段铺满」到「单帧铺满」（手机上可放大到 1 帧粒度）。
- **自适应刻度尺**：主刻度为整秒（`0000` `0001` …，带中心圆点标记精确秒位）；放大后浮现 `5f` `10f` `15f` `20f` … 帧刻度；缩小长视频时主刻度自动变粗（5s / 10s / 分钟），始终不拥挤。
- **真实帧率探测**：解析视频 `moov` 元数据得到真实 fps，驱动帧刻度与单帧步进；探测失败回退 30fps。

## 本地运行
```sh
cd livephoto-web
python3 serve.py          # 默认 http://0.0.0.0:8099
```
手机与电脑在同一局域网时，手机浏览器打开 `http://<电脑IP>:8099` 即可使用。

## 目录说明
- `index.html` / `app.3.js` / `style.3.css` —— 网页本体（原生 JS，无构建步骤）。
- `vendor/mp4-muxer.mjs` —— 导出用的 MP4 封装库。
- `serve.py` —— 本地静态服务器。
